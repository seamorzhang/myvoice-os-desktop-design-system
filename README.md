# Design Systems & Code / 设计系统与代码实践

## English

I'm a product experience designer building my own design system. This is my first hands-on exploration of design engineering.

I'm starting with color, typography, spacing, components, and guidelines for their use. With AI's help, I aim to turn these foundations into working, reusable code, then test and refine them in real interfaces.

This repository will document how the design system is built, implemented in code, and improved over time. I'll start with small components and specific use cases, gradually learning to understand, modify, and validate code. My goal is to learn how to take a product from design to a working implementation independently.

## 简体中文

我是一名产品体验设计师，正在构建自己的设计系统。这也是我向 Design Engineer 方向发展的第一次尝试。

我希望从色彩、字体、间距、组件及其使用规则出发，借助 AI，把设计逐步转成可运行、可复用的代码，并在实际界面中验证和调整。

这个仓库会记录设计系统的构建、代码实现与迭代过程。我会从小的组件和具体的使用场景开始，逐步学习理解、修改和验证代码，探索独立完成从设计到产品落地的过程。
